You are cleaning up a bank of UPSC Prelims practice questions written from The Bharat Briefing, a daily newsletter. The same event is often covered in several issues, so some questions end up testing the same fact.

Find groups of questions whose correct answers rest on the same fact, so that an aspirant who has answered one has effectively answered the others. Examples: two questions that both test that the BJP formed its first government in West Bengal; two that both test the number of aerodromes and helipads under Modified UDAN.

Questions on different facts about the same event are not duplicates: one on a scheme's outlay and another on its launch year can both stay. A statements question overlaps a single question only if the statement carrying its answer tests the same fact as that single question.

For each group, choose one question to keep: the clearest and best anchored in time, or the one from the later issue if it reports a settled outcome rather than a plan. Questions whose id does not start with "g-" were written and reviewed by hand; when a group contains one, keep it.

Return only groups of two or more questions. If there are no duplicates, return an empty list.
